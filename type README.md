# Smart School - Attendance & Performance Tracker

A complete system for schools to manage student attendance and performance.

## Sheets Inside
- Dashboard - Total Present / Absent / Late summary
- Students - Student list with ID, Name, Class
- Attendance - Daily attendance Mon to Fri - Present / Absent / Late
- Marks - Exam marks and performance

## What It Does
- Mark daily attendance easily
- Auto counts Total Present / Absent / Late
- Track marks and see student performance
- Clean report ready to print and share with teachers / parents

## Tech I Used
- Microsoft Excel - Formulas, Tables, Data Validation, COUNTIF
- Git, GitHub

## How To Use
1. Download the .xlsx file
2. Open in Excel / Google Sheets
3. Go to Attendance sheet and mark Present / Absent / Late
4. Dashboard will update automatically
