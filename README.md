# Smart School - Attendance & Performance Tracker

A Full Stack web app for schools to manage student attendance, marks and performance in one place.

## What it does
- Mark daily attendance - Present / Absent / Late
- Add students, classes and subjects
- Add exam marks and see performance
- Dashboard shows total Present / Absent today
- Export attendance report to Excel

## Tech I Used
- Frontend: HTML, CSS, JavaScript, React
- Backend: Node.js, Express.js
- Database: MySQL / MongoDB
- Tools: Git, GitHub, VS Code

## How to Run
1. Clone the repo
2. Install: `npm install`
3. Run: `npm start`
4. Open: `http://localhost:3000`
